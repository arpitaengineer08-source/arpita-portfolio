# Arpita Sharma — Portfolio

A responsive static portfolio focused on **data analytics, business intelligence and applied machine learning**. The site remains a static HTML/CSS/JavaScript project so the existing root-based static deployment does not need a new build configuration.

## Featured projects

- [E-Commerce Intelligence Platform](https://github.com/arpitaengineer08-source/ecommerce-intelligence-platform) — Python ETL, SQL star schema, RFM and cohort analysis, forecasting, churn-risk scoring, Streamlit dashboard and Power BI build kit.
- [VAYU — Air Quality Intelligence](https://github.com/arpitaengineer08-source/vayu-air-intelligence) — air-quality data ingestion, PM2.5 forecasting and pollution-aware scenario analysis for Delhi-NCR, Haryana and Punjab.
- [MovieIQ — Studio Decision Intelligence](https://github.com/arpitaengineer08-source/MovieIQ-Studio-Decision-Intelligence) — movie performance analysis, box-office prediction and budget what-if analysis.
- [NeuroEase](https://github.com/arpitaengineer08-source/neuroease) — FastAPI-based digital mental-health support platform.

## Portfolio sections

About, skills, selected projects with category filters, experience and leadership, Smart India Hackathon recognition, education, coding profiles and contact.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 3000
```

Then visit `http://localhost:3000`.

## Deployment

Static website. Keep the repository root as the publish directory; no Node build step is required.

## Contact form

The form opens a pre-filled email draft in the visitor's default mail app. It does not claim to send messages from the website.
